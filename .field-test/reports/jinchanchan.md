# 心理学拆解报告:金铲铲之战

## 概述

**云顶之弈正版授权手游，8人回合制自动对战，融合策略构筑、概率抽取与排位社交的成瘾性自走棋体验。**

《金铲铲之战》通过清晰的动态反馈（血量、人数对比、警示音效）和随机奖励机制增强了沉浸感与新鲜感，同时以利息规则和通行证进度可视化支持长期策略规划，并通过三星合成和海克斯三选一的动画峰值强化成就感。然而，海克斯限时不可更改的决策、复杂的卡池概率、扣血和降段的负面反馈、通行证倒计时压力以及自动作战的操控感缺失，构成显著的摩擦，易引发焦虑、决策负担和疲乏。伦理层面，产品明显利用损失厌恶、随机抽取（开蛋保底）、赛季清零和社交对比等机制制造紧迫感和沉没成本，可能诱导非理性投入、赌博式消费、过度在线和攀比心理，需警惕对玩家财务和心理健康的风险。

## 产品画像

- 类型:自走棋/Auto Battler手游
- 关键触点:商店刷新动画, 三星合成特效, 海克斯三选一弹窗, 扣血结算, 段位升降动画, 通行证进度条, 小小英雄抽取开蛋
- 核心功能:
  - **单局核心循环** — 8人同场竞技，每回合商店随机刷新5个棋子，花金币购买，三个同名棋子自动合成升星（1星→2星→3星），搭配羁绊（职业/特质）组合上阵，回合自动战斗，战败按对方存活棋子扣血，血量归零淘汰，最终结算1-8名。(用户目标:通过运营和阵容搭配，在随机性中争取前四名甚至吃鸡，获得策略与竞技的智力快感。)
  - **经济与利息系统** — 每回合基础收入+存款利息（每10金币1利息，上限5），连胜/连败额外奖励金币，主动“D牌”（刷新商店）花2金币赌概率，升人口提升高费棋子出现概率——“存钱吃利息”与“梭哈刷牌”的两难贯穿全局。(用户目标:在稳健理财和激进赌牌之间做出选择，管理经济节奏以最大化阵容成型几率。)
  - **概率抽取与卡池** — 商店刷牌本质是概率抽卡，想成三星需要“卡池”里同名棋子，野怪回合掉落装备随机，同一套阵容每局体验不同。(用户目标:享受随机性带来的新鲜感和赌博式惊喜，同时通过策略提高抽到关键棋子的概率。)
  - **海克斯强化三选一** — 每局固定节点弹出强化符文三选一，随机池子决定整局构筑路线，“开出神装/开出废件”成为运气叙事。(用户目标:根据随机强化调整构筑方向，体验不同流派和玩法，并追求高价值强化带来的强度快感。)
  - **排位段位阶梯** — 段位从低到最强王者，单局前四名加分、后四名扣分，赛季末重置回退，冲分保段行为普遍。(用户目标:通过上分获得身份认同和成就感，验证自己的实力，并追逐更高的段位荣誉。)
  - **赛季版本轮换** — 每赛季全套棋子与羁绊换新，强势阵容（T0/T1）榜单与攻略生态发达，玩家常“抄阵容”，版本更新重新洗牌。(用户目标:保持游戏新鲜感，通过学习和模仿强势阵容快速适应新版本，持续获得探索乐趣。)
  - **通行证与外观养成** — 赛季通行证按对局积累经验解锁小小英雄、棋盘、表情等奖励，赛季结束清零；小小英雄通过抽取（蛋/概率）获得，可升星养成，棋盘皮肤单独售卖。(用户目标:收集和展示个性外观，通过通行证获得长期目标感，享受收集养成和概率抽取的乐趣。)
  - **低操作门槛与碎片时间** — 自动战斗无需操作技巧，单局约25-35分钟，可后台挂机，通勤场景友好。(用户目标:在碎片时间轻松游戏，无需高操作负担，同时体验策略的深度和随机性的刺激。)
  - **双人作战模式** — 两人组队共享经济与棋子，可互相支援，社交组队开黑。(用户目标:与朋友协作配合，共享资源，降低单排压力，增强社交互动和合作乐趣。)

## 逐功能心理学拆解

- **单局核心循环** → `dynamic-social-competition·dynamic-comparison`(置信 0.95)
  - 体现:游戏内每回合结束后显示玩家血量条和淘汰顺序，剩余人数越少紧张感越强，玩家会主动调整阵容以争取更高名次，甚至为吃鸡而优化策略。
  - 为何有效:单局核心循环中，系统实时展示玩家血量排名、剩余人数和对手剩余状态，每回合与随机对手对战并在战后显示胜负与名次变化，形成持续动态比较，激发竞争动机和地位追求。
- **单局核心循环** → `dynamic-social-competition·uncertainty-reward`(置信 0.90)
  - 体现:玩家每次野怪回合掉落装备中随机，商店每次刷新的英雄不确定，这种赌博式反馈让玩家为追求稀有英雄或强力装备而反复投入，符合不确定性奖励原则。
  - 为何有效:单局核心循环包含大量不确定奖励：每回合战利品随机掉落、商店英雄刷新随机、选秀环节装备选择随机，奖励结果未知，驱动玩家持续点击和期待，维持参与热情。
- **单局核心循环** → `cumulative-progress-retrieval·loss-aversion-trigger`(置信 0.85)
  - 体现:游戏内剩余血量直观显示，每次失败后血条减少并触发警示音效，玩家会因此调整策略（如更换阵容、刷新商店）以避免被淘汰；连胜时若即将断连胜也会有心理压力，促使其更认真操作。
  - 为何有效:单局中玩家的血量是累积资产，每次战败会扣除血量，当血量接近清零时面临淘汰风险，形成明确的失去预期；同时连胜/连败也有累积效果，连胜被终结会损失额外收益，触发损失厌恶，促使玩家采取挽回行动。
- **经济与利息系统** → `cognitive-biases·loss_aversion`(置信 0.85)
  - 体现:游戏界面明确显示利息规则（每10金币获得1利息），当玩家花费金币后，利息收入减少或清零，直接引发损失感知。
  - 为何有效:玩家在决定是否花费金币时，会感知到花费导致当前金币数减少，从而降低下一回合的利息收益。这种对未来可预见损失的厌恶，使玩家倾向保留金币，以维持或获取利息，规避损失。
- **经济与利息系统** → `cognitive-biases·anchoring`(置信 0.80)
  - 体现:游戏内规则展示利息区间，玩家根据当前金币数可快速计算潜在利息，高额存款目标被反复强化。
  - 为何有效:系统以每10金币为单位计算利息，并设置上限，形成明确的数值锚点。玩家会将存款目标锚定在10的倍数（如30、40、50），以最大化利息收益，从而影响资源分配和消费决策。
- **经济与利息系统** → `cumulative-progress-retrieval·progress-ownership`(置信 0.70)
  - 体现:金币和利息每回合自动结算，数值持续累积并可视化显示，玩家将高额利息视为努力成果，消耗金币时会感到进展被削弱。
  - 为何有效:玩家持续积累的金币数量和相应利息加成形成一种可感知的‘资产进展’，玩家对已有积累产生心理所有权，不愿轻易打破，从而强化存款行为。
- **概率抽取与卡池** → `cialdini-influence·scarcity`(置信 0.80)
  - 体现:游戏中高费英雄的抽取概率远低于低费英雄，且卡池共享、每个英雄总量固定；部分赛季卡池或活动抽取设有时间限制，给玩家稀缺性暗示。
  - 为何有效:卡池中稀有英雄数量有限且抽取概率低，制造了可得性稀缺，同时在部分限时活动或赛季中强化了‘错过就没了’的紧迫感，驱动玩家在有限机会内抓紧抽取。
- **概率抽取与卡池** → `peak-end-rule·peak`(置信 0.75)
  - 体现:当玩家抽取到高费英雄或合成三星棋子时，屏幕触发专属动画、闪亮特效和醒目提示，带来惊喜瞬间，符合峰值设计。
  - 为何有效:抽到稀有棋子时的特效、音效和成就反馈形成强烈的情绪峰值，这种高峰体验被记忆强化，提升玩家对游戏的正面印象和留存意愿。
- **概率抽取与卡池** → `cumulative-progress-retrieval·progress-ownership`(置信 0.70)
  - 体现:部分抽取活动会显示‘距下次保底还差X次’或累计抽取次数，玩家能清晰看到自己的进展，产生‘已投入这么多，不能中断’的心理。
  - 为何有效:抽卡系统中的保底机制通过累计抽取次数让玩家形成进度所有权，明确标注已累积数量，从而强化持续投入的动机并降低中途放弃的可能性。
- **海克斯强化三选一** → `dynamic-social-competition·uncertainty-reward`(置信 0.82)
  - 体现:在《金铲铲之战》对局中,特定回合会弹出海克斯强化选择界面,同时显示三个随机生成的强化符文,强化效果有强有弱,并配有不同稀有度视觉反馈(如金色、彩色边框);玩家必须三选一,且强化会立即生效并与后续阵容组合,直接影响对局胜负和段位晋级。
  - 为何有效:海克斯强化三选一在每局游戏中随机出现,每次提供三个随机且效果差异显著的强化符文,玩家无法预知刷新内容,这种奖励内容的不确定性与竞争结果未知共同激发玩家的好奇心和博弈冲动,驱动其为了获取更强组合而持续参与对局并追求竞技优势。
- **排位段位阶梯** → `dynamic-social-competition·dynamic-comparison`(置信 0.95)
  - 体现:游戏内显示当前段位、升降级动画以及好友/服务器排名对比，使玩家清晰感知自己在竞争中的位置变化。
  - 为何有效:段位阶梯将玩家置于一个动态可比的社会层级中，实时更新的段位和排名强化了与他人比较的心理，驱动玩家提升或维持地位。
- **排位段位阶梯** → `dynamic-social-competition·matched-challenge`(置信 0.90)
  - 体现:排位匹配机制会参考隐藏分和段位区间，保证对局双方实力接近，并在晋级赛时设置关键性挑战。
  - 为何有效:排位系统根据玩家历史表现匹配相近段位的对手，使每场对局具有适度挑战性，既不过易也不过难，持续激发挑战动机。
- **排位段位阶梯** → `cumulative-progress-retrieval·progress-ownership`(置信 0.85)
  - 体现:每个段位内有小段位（如青铜I、II、III）和胜点进度条，直观呈现距离下一段位的差距，强化累积进展的拥有感。
  - 为何有效:段位阶梯以明确的层级和胜点进度展示玩家投入的累积成果，玩家对已获得的段位和胜点产生心理所有权，从而更愿意继续投入。
- **赛季版本轮换** → `dynamic-social-competition·dynamic-comparison`(置信 0.85)
  - 体现:游戏内新赛季段位继承规则、排行榜数据刷新、与好友排名对比等设计。
  - 为何有效:赛季版本轮换会重置段位和排行榜，使玩家重新进入动态比较的竞争环境。段位继承制度让玩家看到自己和好友的排名变化，激发竞争动机，驱动持续参与排位赛。
- **赛季版本轮换** → `cognitive-biases·loss_aversion`(置信 0.70)
  - 体现:赛季结束公告强调结算与重置，玩家担心掉段而提升活跃度，版本替换时对旧赛季奖励的失去感。
  - 为何有效:赛季重置使玩家面临段位下降或奖励清零的损失预期。为避免失去已有的段位和赛季奖励，玩家会在赛季末期积极冲分或购买版本内容，从而强化付费与留存。
- **通行证与外观养成** → `cumulative-progress-retrieval·progress-ownership`(置信 0.85)
  - 体现:界面常态显示通行证当前等级、剩余经验值及每个等级对应的外观奖励；玩家积累的代币和已解锁外观会明确陈列，形成‘已经走了这么远’的心理沉没成本。
  - 为何有效:通行证通过明确的等级进度条、累积经验值和分阶段解锁奖励，让玩家对已获得的进度和外观资源产生强烈所有权感，从而持续投入时间以维持和推进进度。
- **通行证与外观养成** → `cognitive-biases·loss_aversion`(置信 0.80)
  - 体现:通行证界面显示赛季剩余天数，强调‘赛季限定’、‘错过不再返场’；未领取的奖励在赛季结束时会消失，给玩家明确的预期损失。
  - 为何有效:赛季限定的通行证与外观让玩家感知到‘如果不及时完成或购买就会永久失去’，损失厌恶会放大错过成本，推动玩家在赛季结束前继续上线、完成任务或购买通行证。
- **通行证与外观养成** → `cialdini-influence·scarcity`(置信 0.80)
  - 体现:通行证中的稀有外观标注‘赛季限定’或‘限时获取’，并配合倒计时、剩余天数提示；商城中限定外观的‘即将下架’标签也属于同一机制。
  - 为何有效:稀缺性提升物品感知价值与紧迫感，限时赛季和限定标签让玩家觉得通行证外观是‘难得的机会’，从而激发即时购买和活跃行为。
- **通行证与外观养成** → `peak-end-rule·peak`(置信 0.70)
  - 体现:每升一级会出现奖励领取动效，解锁传说级外观时配有特殊动画、音效和成就提示；这些设计刻意制造‘惊喜时刻’，形成峰值体验。
  - 为何有效:通行证升级或解锁稀有外观时的高光体验会成为玩家记忆中的情绪峰值，使漫长的养成过程被关联为正反馈，提升对通行证整体的满意度和付费意愿。
- **通行证与外观养成** → `peak-end-rule·end`(置信 0.60)
  - 体现:赛季通行证达到满级后会出现完成总结页，展示已收集外观总数、最终奖励和赛季回忆；赛季结算时也会提示获得限定奖励，强化收尾体验。
  - 为何有效:赛季结束时的结算画面和获得最终外观的完成感会影响玩家对整期通行证的回顾评价，好的结尾能让玩家产生成就感并期待下个赛季。
- **低操作门槛与碎片时间** → `cognitive-biases·default_effect`(置信 0.75)
  - 体现:游戏提供'自动作战'功能，以默认开启状态辅助玩家操作；开局时默认推荐最优阵容，玩家可一键采用，无需手动配置；匹配模式默认选择快速匹配，缩短等待时间，适应碎片化时间。
  - 为何有效:低操作门槛通过默认简化操作、自动执行关键步骤，减少用户的决策与操作负担，让用户无需额外思考即可进入游戏。碎片时间场景下，用户希望快速完整体验，默认设置（如自动战斗、推荐阵容）极大降低了参与成本，契合默认效应中'用户倾向于接受预设选项'的机制。
- **双人作战模式** → `dynamic-social-competition·dynamic-comparison`(置信 0.85)
  - 体现:游戏内双人作战有独立的段位和排行榜，每局结束后显示双方队伍的总分和排名变动，队友间可比较贡献，增强竞争氛围。
  - 为何有效:双人作战模式中，玩家与队友组成小队，与另一支小队实时对战，系统会展示段位、积分和排名变化，队友之间形成动态比较，激发竞争动机。
- **双人作战模式** → `dynamic-social-competition·matched-challenge`(置信 0.80)
  - 体现:游戏匹配系统按照双人段位区间匹配对手，确保对局双方整体实力接近，每一场都有竞技性和不确定性。
  - 为何有效:双人作战会根据双方队伍的历史表现和段位进行匹配，提供实力相当的对手，保证挑战的刺激性，同时避免碾压或无力感。
- **商店刷新动画** → `peak-end-rule·peak`(置信 0.85)
  - 体现:刷新时英雄头像快速旋转、显著的光效和音效提示，尤其出现高费或关键英雄时动画表现明显增强，呼应'惊喜时刻/成就动画'等峰值触发线索。
  - 为何有效:商店刷新动画通过在刷新结果揭晓瞬间加入视觉特效、音效和节奏控制，放大玩家随机获得英雄时的情绪反应，创造明确的情绪峰值，使该体验在记忆中更为突出。
