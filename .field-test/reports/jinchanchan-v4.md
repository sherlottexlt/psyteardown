# 心理学拆解报告:金铲铲之战

## 概述

**腾讯代理的《云顶之弈》手游版,8人同场竞技的自走棋,融合构筑策略与概率抽取。**

该产品通过丰富的峰值时刻、损失厌恶、进度可视化、社会认同和周期重置等设计，有效提升了玩家的参与度与留存，同时低操作门槛降低了启动成本。然而，过度依赖损失厌恶和限时压力可能导致玩家挫败感与强迫性游玩，开蛋概率不透明和双人协作冲突进一步削弱体验。伦理上，需警惕利用冲动消费、错过恐惧和沉没成本进行过度刺激，并避免从众机制压抑自主探索。整体呈现强驱动与高风险并存的特征，需在激励与玩家福祉间谨慎平衡。

## 产品画像

- 类型:自走棋/Auto Battler手游
- 关键触点:商店刷新动画, 三星合成特效, 海克斯三选一弹窗, 扣血结算, 段位升降动画与胜点进度, 通行证进度条, 阵容强度榜单, 小小英雄开蛋
- 核心功能:
  - **单局核心循环** — 8人同场竞技,每回合商店随机刷新5个棋子,花金币购买,三个同名棋子自动合成升星(1星→2星→3星),搭配羁绊(职业/特质)组合上阵,回合自动战斗,战败按对方存活棋子扣血,血量归零淘汰,最终结算1-8名。(用户目标:通过构筑阵容和随机应变,争取更高名次,获得智力快感与胜利体验。)
  - **经济与利息系统** — 每回合基础收入+存款利息(每10金币1利息,上限5),连胜/连败额外奖励金币,主动“D牌”(刷新商店)花2金币赌概率,升人口提升高费棋子出现概率——“存钱吃利息”与“梭哈刷牌”的两难贯穿全局。(用户目标:在资源有限的情况下做出最优经济决策,平衡眼前战力与长期收益,体验策略博弈。)
  - **概率抽取与共享卡池** — 商店刷牌是纯概率抽取,全服玩家共享同一卡池,想成三星需要卡池里还剩足够同名棋子,野怪回合掉落装备随机,同一套阵容每局体验不同。(用户目标:享受随机性带来的每一局新鲜感,同时通过卡池机制规划自己的拿牌策略。)
  - **海克斯强化三选一** — 每局固定节点弹出强化符文三选一,随机池子决定整局构筑路线,“开出神装/开出废件”成为运气叙事,选定后本局不可更改。(用户目标:根据随机强化快速调整构筑方向,体验运气与决策结合的快感。)
  - **排位段位阶梯** — 段位从低到最强王者,单局前四名加分、后四名扣分,段位内以胜点累积,接近晋级线时“就差几分上分”的冲刺感明显,赛季末重置回退,冲分保段行为普遍。(用户目标:通过竞技表现获得段位身份认同,追求上分和保段的成就感。)
  - **攻略生态与阵容榜单** — 第三方攻略社区、数据站与主播内容高度发达,按吃鸡率/前四率给出阵容强度榜(T0/T1 分级),玩家开局前后查榜“抄阵容”,版本更新后榜单重排,“大家都在玩什么阵容”直接影响个人选择。(用户目标:获取外部信息辅助决策,降低学习成本,跟随主流阵容提高胜率。)
  - **赛季版本轮换** — 每赛季全套棋子与羁绊换新,已熟悉的阵容知识作废,需重新学习。(用户目标:持续获得新鲜感,体验游戏环境变化带来的策略重构。)
  - **通行证与外观养成** — 赛季通行证按对局积累经验解锁小小英雄、棋盘、表情等奖励,界面常显剩余天数与距下一级所需经验,赛季结束未解锁部分清零;小小英雄通过开蛋抽取获得,可升星养成,棋盘皮肤单独售卖。(用户目标:通过外观收集和养成展示个性,获得收集成就感和社交认同。)
  - **低操作门槛与碎片时间** — 自动战斗无需操作技巧,单局约25-35分钟,可后台挂机,通勤场景友好。(用户目标:在碎片时间轻松游玩,无需高操作负担,享受策略对弈。)
  - **双人作战模式** — 两人组队共享经济与棋子,可互相支援,社交组队开黑。(用户目标:与朋友合作互动,增加社交乐趣和团队协作体验。)

## 逐功能心理学拆解

- **单局核心循环** → `peak-end-rule·peak`(置信 0.82)
  - 体现:对局中合成三星英雄会有专属出现动画和音效，战斗关键回合有慢镜头特效；官方宣传中也常突出“三星五费”、“极限翻盘”等高峰场景，证明这些峰值时刻是体验记忆锚点。
  - 为何有效:单局战斗中的高光时刻（比如合成三星英雄、关键回合翻盘、大招团战特效等）构成情绪峰值，极大增强玩家对整局体验的正面记忆。玩家在回忆对局时往往优先想起这些瞬间，而非漫长的运营过程。
- **单局核心循环** → `peak-end-rule·end`(置信 0.78)
  - 体现:对局结束展示结算页，获得第一时有“吃鸡”胜利动画和专属庆祝音效；失败时也有“下次加油”类文案，并快速引导进入下一局。这些结尾设计可在游戏录屏和玩家分享中常见。
  - 为何有效:每局结束时的结算反馈（胜利/失败、最终排名、伤害统计、吃鸡动画）构成明确的结尾体验。根据峰终定律，结尾质量直接影响玩家对整局的评价以及是否立刻再来一局。
- **单局核心循环** → `cognitive-biases·loss_aversion`(置信 0.74)
  - 体现:游戏界面明确显示血量数值与颜色变化，当血量低于阈值时出现红色警示边框和心跳音效，且玩家需要面对“再输一次就可能被淘汰”的现实风险；社区经常讨论“锁血”和“保血量”策略，体现损失厌恶对行为的影响。
  - 为何有效:单局内玩家的生命值（小小英雄血量）是有限且持续减少的资源，每次战斗失利都会等量扣血，濒危时会强烈唤起“即将失去本局所有投入”（成型阵容、段位晋级机会）的恐惧，驱动玩家更投入、更谨慎地决策。
- **经济与利息系统** → `cognitive-biases·loss_aversion`(置信 0.85)
  - 体现:游戏每回合根据当前金币存量发放利息，每10金币额外获得1金币（上限5）。玩家在购买棋子时需要权衡是否消耗金币，因为消耗会直接导致后续利息减少，这种对未来收益的牺牲构成了心理损失，驱动玩家倾向于保留金币。
  - 为何有效:利息机制使玩家在花费金币时面临潜在损失（失去未来的利息收入），从而利用损失厌恶心理促使玩家主动积累和保留金币。
- **概率抽取与共享卡池** → `cialdini-influence·scarcity`(置信 0.82)
  - 体现:在游戏中，玩家可以按下快捷键查看当前卡池中各英雄的剩余数量，当看到热门英雄被其他玩家大量获取后剩余数量减少，会产生稀缺感知。
  - 为何有效:共享卡池中每个英雄的库存数量有限，玩家抽取会消耗库存，导致可获得的英雄数量逐渐减少，形成限量感，从而激发获取欲望。
- **概率抽取与共享卡池** → `cognitive-biases·loss_aversion`(置信 0.75)
  - 体现:游戏内英雄池数量有限，当玩家核心卡被卡死（他人持有较多）时，玩家会感受到晋升三星或完整阵容的困难，从而产生损失厌恶而加快刷新。
  - 为何有效:玩家在追求特定英雄时，发现其他玩家已经拿走了多张，导致自己凑齐强力阵容的可能性降低，这种即将失去机会的感受促使玩家提前行动，避免损失。
- **概率抽取与共享卡池** → `cognitive-biases·bandwagon`(置信 0.60)
  - 体现:版本强势阵容的常用英雄往往在卡池中被快速抢空，玩家通过观察对手棋盘或卡池剩余情况，会发现大家都在使用同一阵容，从而跟风选择。
  - 为何有效:共享卡池中消耗量大的英雄反映了当前主流玩法，玩家观察到其他玩家都在争抢同一批英雄，会认为这是强势选择而跟随，产生从众效应。
- **海克斯强化三选一** → `peak-end-rule·peak`(置信 0.65)
  - 体现:游戏在2-1、3-2、4-2等阶段强制弹出三个强化供选择，选择后立即触发效果变化，伴随特效和数值变动，形成明确的情绪冲击点；玩家在回忆对局时更容易想起'那次拿到XX海克斯'的峰值体验。
  - 为何有效:海克斯强化三选一是对局中的关键决策节点，每次选择都可能产生强力效果或戏剧性转折，创造情绪峰值，而玩家的记忆更倾向于记住这些高光或低谷时刻，而不是整体平局体验。
- **排位段位阶梯** → `cumulative-progress-retrieval·progress-ownership`(置信 0.90)
  - 体现:游戏主界面或排位页显示玩家当前段位（如钻石III）和段位内进度条，明确显示距离下一段位还需多少胜点或星星，每次胜利/失败后进度条变动。这种进度累积可视化是进展所有权的典型体现。
  - 为何有效:排位段位阶梯将玩家的游戏表现转化为可量化的段位等级和段内进度（如胜点、星星），直接展示玩家已获得的成就。这种明确的累积进展标注使玩家对当前段位产生心理所有权，为维持段位或继续晋级提供持续动机。
- **排位段位阶梯** → `cyclical-ownership-reset·grant-temporary-entitlement`(置信 0.85)
  - 体现:游戏明确划分赛季节点，当前段位伴随赛季编号和起止时间；赛季结束时，段位按规则重置（如新赛季开始需重新定位）。段位图标上常标注‘当前赛季’或‘S12’，强调其时效性。
  - 为何有效:排位赛以赛季为单位，玩家在赛季内获得的段位具有时效性，赛季结束后段位会被重置或折衰减。这种临时所有权机制让玩家将当前段位视为‘我的胜利果实’，一旦失去会感到损失，从而在赛季期间投入更多游戏以维护或提升段位。
- **排位段位阶梯** → `cyclical-ownership-reset·visible-expiry-cadence`(置信 0.80)
  - 体现:排位界面常在显著位置显示‘本赛季只剩X天’或‘赛季结算倒计时’，甚至在段位阶梯旁加入剩余天数。这些倒计时元素是可见失效节律的直接证据。
  - 为何有效:通过界面上可见的赛季倒计时或段位相关限期任务，让玩家明确感知到段位有效期即将结束。这种时间压力强化了‘现在不冲分就会失去段位’的认知，驱动玩家在周期内保持活跃。
- **攻略生态与阵容榜单** → `cialdini-influence·social_proof`(置信 0.87)
  - 体现:游戏内展示热门阵容的出场率、胜率、平均排名等数据，并配有「最受欢迎」「主流上分」等标签，同时附带“X人正在使用”类提示，这些可量化的选项构成典型社会认同线索。
  - 为何有效:玩家在低压力的游戏决策场景中，通常缺乏独立的阵容验证能力，会借助大众数据来降低选择风险。榜单明确展示当前版本其他玩家的主流选择与胜率数据，形成显著的社会证明，驱动玩家模仿或跟风，从而增强对平台的信任与粘性。
- **攻略生态与阵容榜单** → `cognitive-biases·bandwagon`(置信 0.84)
  - 体现:阵容榜单依据玩家实时使用次数与推荐度进行热度排序，并突出显示榜首方案，形成显而易见的“最受欢迎”标签，属于从众效应的直接应用，非纯界面推测。
  - 为何有效:当榜单以热度排序并突出「版本答案」时，玩家会不自觉地产生「大家都在用，所以我也应该用」的从众判断，尤其是面对平衡性高度动态的自走棋玩法，这种效应会加速特定阵容的流行和扩散。
- **赛季版本轮换** → `cyclical-ownership-reset·visible-expiry-cadence`(置信 0.75)
  - 体现:排位入口及赛季界面展示赛季剩余时间，战令系统显示结束倒计时，赛季专属奖励有领取截止日期。
  - 为何有效:赛季轮换以明确倒计时和剩余天数展示当前拥有的段位、战令或限定奖励即将到期，让用户持续感知到资产的临时性，从而在周期内维持活跃。
- **赛季版本轮换** → `cyclical-ownership-reset·impending-loss-framing`(置信 0.70)
  - 体现:赛季末公告明确“段位即将重置”，战令界面提醒“奖励即将过期”，排位段位图标在结算前高亮展示当前段位。
  - 为何有效:赛季结束意味着段位重置、排名清零或未领取奖励作废，将“停止活跃”体验为“失去已获得的位置与奖励”，利用损失厌恶驱动末期冲分与回访。
- **赛季版本轮换** → `cyclical-ownership-reset·re-entry-loop`(置信 0.70)
  - 体现:新赛季开启后重新定位段位，战令进度清零并开启新目标，限定小小英雄或棋盘通过新赛季途径再度获取。
  - 为何有效:新赛季重新开放定级、新一期战令与限定奖励，让用户重新经历获取—持有—失去—再获取的循环，形成固定的回归节奏。
- **通行证与外观养成** → `cyclical-ownership-reset·grant-temporary-entitlement`(置信 0.85)
  - 体现:通行证提供赛季专属的小小英雄蛋、棋盘皮肤，并标注‘赛季限定’，玩家购买后获得但仅在当前赛季内有效。
  - 为何有效:通行证授予玩家赛季限定的外观资产，形成临时所有权，让玩家产生‘这些东西已经属于我’的占有感。
- **通行证与外观养成** → `cyclical-ownership-reset·visible-expiry-cadence`(置信 0.90)
  - 体现:通行证主界面顶部显示‘剩余X天’，赛季结束前出现倒计时提醒。
  - 为何有效:通行证界面直接展示剩余天数与赛季结束倒计时，让用户持续感知所有权的时限性，驱动周期性活跃。
- **通行证与外观养成** → `cyclical-ownership-reset·impending-loss-framing`(置信 0.80)
  - 体现:通行证奖励页提示‘赛季结束后未领取奖励将失效’，赛季末通过弹窗强调清空风险。
  - 为何有效:赛季临近结束，未领取的等级奖励会被收回，把‘停止参与’体验为‘失去已拥有的东西’，触发损失厌恶促使玩家继续行动。
- **通行证与外观养成** → `cumulative-progress-retrieval·progress-ownership`(置信 0.70)
  - 体现:通行证界面显示当前等级、经验值及已解锁奖励数量，外观图鉴展示收集百分比和已拥有数。
  - 为何有效:通行证等级与外观收集度以进度条和数量形式明确展示，玩家对已积累的进度产生心理所有权，从而愿意持续投入。
- **低操作门槛与碎片时间** → `cognitive-biases·default_effect`(置信 0.60)
  - 体现:金铲铲之战采用自动战斗机制，玩家只需放置棋子、选择阵容，操作简单；对局可在碎片时间进行，产品未强制用户投入长时段，使开始游戏成为低成本的默认选择。
  - 为何有效:低操作门槛意味着用户无需复杂学习或决策即可开始游戏，相当于产品预设了默认参与路径，降低启动阻力；碎片时间适配则使用户在短暂空闲时更容易选择开始，进一步强化默认行为。
- **双人作战模式** → `cialdini-influence·liking`(置信 0.65)
  - 体现:模式提供好友邀请入口和组队界面，可显示好友在线状态；玩家可与好友共同决策、互相支援，这种协作体验强化了人际亲密度。
  - 为何有效:双人作战模式的核心是与朋友或好友组队进行游戏，利用玩家对熟悉同伴的喜好和信任，增强游戏过程的情绪体验和参与意愿。这种社交绑定使玩家更愿意持续游戏，并可能通过好友关系带动新用户加入。
- **双人作战模式** → `cognitive-biases·loss_aversion`(置信 0.60)
  - 体现:战斗界面显示共享生命值条，低血量时会有红色警示或闪烁；在关键回合可能出现‘即将被淘汰’或‘段位将降低’的提示，促使玩家采取挽救措施。
  - 为何有效:双人作战模式中，队伍共享生命值，生命值下降时玩家感受到的损失更加直接和强烈。同时，失败可能导致排位分下降或连胜中断，这些‘将失去’的提示触发了损失厌恶，驱动玩家投入更多注意力与游戏行为以避免损失。
