# 心理学拆解报告:潮汐

## 概述

**主打白噪音、专注计时与睡眠助眠的正念类App**

潮汐通过专注计时、呼吸引导和即时成就反馈，有效支持心流体验与内在动机，但连续打卡清零、会员促销暗黑模式及数据社交化等机制，依赖损失厌恶驱动活跃，可能引发挫败、焦虑与伦理风险，需平衡激励策略以契合正念初衷。

## 产品画像

- 类型:正念类App
- 关键触点:专注计时全屏页, 专注结束结算页, 睡前提醒推送, 冥想课程列表页, 数据统计图表页, 会员付费墙, 连续天数展示
- 核心功能:
  - **白噪音音景库** — 雨声、海浪、森林、咖啡馆等自然与环境音，可单独播放或叠加混音，支持定时关闭。(用户目标:通过多种环境音创造放松、专注或助眠的氛围。)
  - **专注计时** — 番茄钟式计时器，配合音景使用，计时中界面为极简全屏，退出会中断本次专注记录。(用户目标:利用计时与音景结合提升专注力，并记录专注时长。)
  - **睡眠模块** — 睡前助眠音频与睡眠故事，支持设置入睡定时与起床闹钟，记录入睡与起床时间。(用户目标:缓解入睡困难，养成规律作息，了解睡眠情况。)
  - **冥想课程** — 按主题分为多个系列（如缓解焦虑、提升专注），每系列由多节音频课组成，按顺序推进，部分课程需会员解锁。(用户目标:通过系统化的冥想练习缓解焦虑、提升专注力。)
  - **数据统计** — 按日/周/月汇总专注时长、冥想次数、睡眠时长，以图表呈现趋势。(用户目标:直观查看练习与睡眠数据，追踪自己的进步。)
  - **连续记录** — 显示连续使用天数，中断后计数归零重来。(用户目标:利用连续天数激励自己保持每日练习。)
  - **会员订阅** — 年费/月费解锁全部课程与高级音景，新用户有免费试用期，到期自动续费。(用户目标:解锁完整内容与高级功能，获得完整体验。)
  - **呼吸引导** — 动画随呼吸节奏缩放，引导用户跟随吸气与呼气。(用户目标:通过视觉引导快速进入平静状态，辅助冥想或放松。)
  - **分享卡片** — 可将专注时长或冥想记录生成图片卡片分享到社交平台。(用户目标:将个人练习成果以图片形式分享到外部平台。)

## 逐功能心理学拆解

- **白噪音音景库** → `flow·clear_goals`(置信 0.35 ⚠️低置信)
  - 体现:推测：音景库中存在场景分类标签（如“专注”“睡眠”），帮助用户快速明确当前需求
  - 为何有效:音景库按场景分类（如专注、睡眠、放松）为用户提供清晰的选择目标，用户通过分类即可快速定位所需音景，降低认知负荷，从而更容易进入专注状态。
- **白噪音音景库** → `cialdini-influence·social_proof`(置信 0.40 ⚠️低置信)
  - 体现:推测：音景库可能包含热门/推荐排序或使用人数显示（参考同类白噪音应用常见设计）
  - 为何有效:音景库中常通过“热门”“推荐”等标签展示他人的选择，利用社会认同心理降低用户的决策成本，增加对音景的信任感和使用意愿。
- **专注计时** → `flow·clear_goals`(置信 0.70)
  - 体现:界面要求用户先设定一个明确的专注时长，然后开始计时，期间主任务聚焦于“完成这段时间”。
  - 为何有效:专注计时以用户自选的时长（如15/25/45分钟）作为清晰单一目标，减少行动犹豫，帮助进入心流状态。
- **专注计时** → `flow·immediate_feedback`(置信 0.75)
  - 体现:计时过程中显示倒计时数字或环形进度条，实时反馈剩余时间；结束时给予提示或庆祝动效。
  - 为何有效:倒计时数字或进度环的实时变化提供持续反馈，让用户感知时间流逝与目标达成进度，维持专注投入。
- **专注计时** → `cumulative-progress-retrieval·progress-ownership`(置信 0.40 ⚠️低置信)
  - 体现:历史专注记录、累计专注时长、连续专注天数在个人统计中明确展示（推测，具体界面未直接观察）。
  - 为何有效:专注计时结束后会累积专注时长、连续专注天数等数据，用户对这些积累产生所有权感，从而更愿意持续使用。
- **睡眠打卡** → `cumulative-progress-retrieval·progress-ownership`(置信 0.80)
  - 体现:睡眠模块提供每日打卡功能，页面显著位置展示当前连续打卡天数（如「已连续打卡 N 天」），并可在日历中查看已打卡的日期记录。
  - 为何有效:用户在睡眠模块中频繁进行打卡操作，连续天数清晰可见，使这些累积数据成为用户的心理资产，从而更愿意持续打卡以维持已拥有的进展。
- **睡眠打卡** → `cumulative-progress-retrieval·loss-aversion-trigger`(置信 0.60)
  - 体现:若用户某天未打卡，连续打卡天数会重置为 0，且打卡页面的日历中该天为空白，与已打卡日期形成对比，暗示进展的断裂。
  - 为何有效:当用户错过打卡，连续天数归零，之前积累的进展被突然清零，用户会因失去已有成果而产生损失厌恶，进而为防止中断而保持打卡行为。

  - 为何有效:用户在冥想课程中积累连续打卡天数和累计时长，持续投入形成心理所有权，从而更愿意维持使用。

- 将“连续打卡”改为“弹性目标”（如每周至少5天）或引入“休息日”概念，减少因单次中断而产生的放弃心理，提升长期留存。
