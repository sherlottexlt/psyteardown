# 设计启发式采用三阶段知识增长

## Status

accepted

Design Heuristic 按 observation → candidate → approved 三阶段增长。单次案例/实验只能形成 Heuristic Observation；多个相关案例或较完整实验可形成 Heuristic Candidate，必须记录适用情境、支持案例、反例、机制解释、混淆变量和限制；至少 2–3 个独立案例/实验且经人工审批后才成为 Approved Design Heuristic。已批准启发式只能作为 suggest 参考，不能默认影响设计生成、触发 blocked 或替代 DesignBrief。
