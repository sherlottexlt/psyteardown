# V1 使用规范设计变量词汇

## Status

accepted

V1 建立受限 Canonical Design Variable 词汇，覆盖介入模态/时机/强度/可见性/确认与撤销动作、情境推断与隐私、材料/握持/触觉、重量/续航/单手操作等变量。每项有稳定 variable_id、value_type、允许值/单位、来源要求、适用场景和风险相关性；Candidate Composition、Variable Repair Trace、Criterion Assessment 和 Next Prompt 只能引用稳定 ID。自由描述绑定不到现有变量时形成候选，需人工确认后进入词汇。
