# 反馈模态使用影响属性画像而非总强度

## Status

accepted

V1 为 private_haptic、public_audio、visual、in_ear_voice 等反馈模态建立 Modality Profile，至少描述 privacy_exposure、attention_capture、discoverability、persistence、social_visibility、interruptibility、reversibility 和 user_effort。画像用于 DesignBrief 下的多目标比较，不压缩成跨模态总强度或心理分数，也不等于实测结果；属性可来自候选声明、机制知识或人工确认，样机/实验结果通过新版本更新。discoverability 不能抵消隐私或控制风险。
