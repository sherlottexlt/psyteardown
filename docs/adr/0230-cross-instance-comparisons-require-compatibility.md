# 跨实例比较先检查兼容性

## Status

accepted

不同 Project Instance 的结果只有通过 Comparison Compatibility 才能正式比较：同一/兼容 Brief、Scenario、Candidate/Condition Snapshot、变量词汇 mapping、Mechanism/Rule、Experiment Protocol、AnalysisRun、Outcome Measure、样本分群和资产完整性必须可追溯。比较状态为 comparable、conditionally_comparable 或 not_comparable；后者不计算“更好”、总差异或自动偏序，前者/条件可比者创建独立 Comparison Revision，显示所有依赖差异和证据限制，不改变源实例。
