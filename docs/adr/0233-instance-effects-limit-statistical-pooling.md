# 实例效应决定跨实例池化资格

## Status

accepted

跨实例结果记录 Instance Effect Status：controlled、measured、adjusted、suspected 或 unknown。只有 controlled/measured，或按预注册分析计划完成 adjusted，才可申请 poolable；suspected/unknown 只能分实例报告、conditionally_comparable 或 exploratory，不能让 LLM 声称批次效应已消除。Pooling Approval 由人批准，绑定实例差异、Consent Scope、分析计划和新 Derived Dataset/AnalysisRun；相同设备型号不自动视为无实例效应。
