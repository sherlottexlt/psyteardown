# 实验必须预注册并经过结果审阅

## Status

accepted

Explore 只生成 ExperimentPlan 草案；涉及用户研究的计划必须经人工审查同意/退出、变量、混淆、成功判据和停止规则，形成不可静默修改的 Preregistered Experiment，之后才能 approved_to_run。执行后结果由人工进行 Result Review，结合原始数据、分析版本和预注册判据，将假设标为 supported、rejected、inconclusive 或 needs_replication；失败和无效结果同样保留。模型不能直接更新假设状态。这样避免事后改判据和过度解释；代价是实验闭环包含必要的研究治理步骤。
