# 参与者研究数据不得以原始形式进入生成 prompt

## Status

accepted

V1 默认禁止把原始访谈、日志、音频、视频或单个参与者的详细反馈放入下一轮 AI 设计 prompt/few-shot。只有形成无法直接回溯个人的 Aggregated Research Insight，且参与者 consent_scope 允许 remote_model_processing/model_training_use（按具体用途）、达到 Minimum Aggregation Sample、通过重识别检查和 Pre-Transfer Preview，才可作为可选参考；knowledge_growth、internal_method_research、public_showcase 授权不互相替代。撤回相关用途后停止使用并做影响分析。
