# 真人结果使用结构化 OutcomeObservation

## Status

accepted

Real-User Outcome Evidence 必须以 OutcomeObservation 记录，至少绑定 hypothesis、candidate revision、participant group、sample size、scenario/Brief snapshot、task、condition、measure、value/unit、collection method、raw_data_ref、analysis_run_id、uncertainty、limitations 和 consent。自报告保留量表/问题原文，访谈保留匿名参与者 ID、逐字原话和编码版本，行为数据保留原始数据与分析脚本。缺字段、缺方法或无法确认同意的结果标记 Unusable Result，不能推进 observed/supported/replicated；“用户喜欢”不能替代结构化结果。
