# V1 对照无辅助评审和通用 LLM 评审

## Status

accepted

psyteardown 的外部效用评测至少包含 Unaided Review Baseline、Generic LLM Review Baseline 和结构化 Treatment 三组，使用相同 DesignBrief 与候选，并通过随机顺序或 counterbalancing 控制学习污染。比较风险召回、编造事实、反馈可执行率、下一轮变量采用/问题改善、排序理由理解、审阅耗时、覆盖质量和未知/竞争假设保留；指标与判据在实验前锁定，不使用报告长度或专业措辞。这样能证明相对现有“抽卡 + 凭经验选”的增量价值。
