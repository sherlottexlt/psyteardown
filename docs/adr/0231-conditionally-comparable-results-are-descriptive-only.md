# 条件可比结果只做描述性表达

## Status

accepted

conditionally_comparable 的跨实例比较必须附带依赖差异清单，只允许“在相同任务/近似场景下观察到……”等条件化描述、限制和 Replication Proposal，不产生“更好”、综合排名、正式 Candidate Partial Order、Design Heuristic 支持或因果归因。它不进入启发式支持计数；人工引用标记 contextual_comparison，LLM 只能使用受限措辞。统一协议复测需新 Project Instance 和新 Comparison Revision。
