# 池化不自动提高 Outcome Evidence Strength

## Status

accepted

跨实例 full/stratified/exploratory pooling 只创建新的 Derived Dataset 和 AnalysisRun，不自动提高 Outcome Evidence Strength。只有重新检查同一假设、条件/测量兼容、参与者与运行独立性、预注册协议、缺失策略和 Instance Effect，并经人工 Result Review 后，才可创建 Evidence Strength Change；记录 from/to、independent_replication/larger_sample/protocol_consistency/cross_instance_consistency 等依据和限制。exploratory_only 保持 exploratory，方向冲突为 mixed/inconclusive；更多数据或实例不等于独立复现。
