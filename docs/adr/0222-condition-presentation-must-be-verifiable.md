# 实际呈现条件必须可验证

## Status

accepted

每次正式参与者暴露创建 Condition Presentation Record，记录 condition snapshot、实际资产/配置 hash、设备/软件版本、校准状态、时间/时长、操作员、日志和偏离；OutcomeObservation 必须引用该记录。数字原型保存实际配置/事件日志，样机保存 prototype/校准和可用传感器证据，纸面/模拟条件保存脚本/图像 hash。无法证明一致时标记 presentation_unverified，结果不能作为主要 Outcome Evidence，只能 exploratory 或按预注册处理。
