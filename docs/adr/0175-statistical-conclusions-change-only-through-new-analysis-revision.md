# 统计结论只能通过新分析修订改变

## Status

accepted

人工可创建 Editorial Summary Revision，调整措辞、顺序、术语和已有限制，但不能直接改变 Analysis Result 的方向、效应、证据强度、样本、判据或限制。若认为数据、脚本、预注册或解释有问题，必须提交 Analysis Challenge（data_error/script_error/preregistration_issue/interpretation_issue/missing_context），修复后创建新分析 revision，再生成新摘要和 Result Review；公开报告显示摘要与分析版本绑定。
