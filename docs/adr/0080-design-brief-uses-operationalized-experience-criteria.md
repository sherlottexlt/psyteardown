# DesignBrief 使用操作化体验准则

## Status

accepted

DesignBrief 的 desired experiences 不再是自由字符串，而引用 ExperienceCriterion。每个准则包含 operational_definition、desired_direction、observable_indicators、prohibited_indicators、applicable_scenarios、evidence_required、priority 和 tie_break_policy，并可引用多个 Mechanism Card。候选偏序只使用冻结简报中的准则；“更自然”“更亲近”等无法操作化的目标会阻止 Brief 冻结，新增或修改准则需要新 Brief revision。这样让体验评审有可观察基准，而不是模型自由解释形容词。
